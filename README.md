# autograd-cpp

A from-scratch autograd engine + Neural ODE solver in modern C++, with a real-time visualizer.

No ML libraries. Everything - tensors, reverse-mode autodiff, optimizers, ODE solvers, the adjoint method - is built from the ground up.

**Day 1 (2026-10-10):** building module A1 - the scalar autodiff core.
